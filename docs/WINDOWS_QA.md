# Windows 手工验收清单

以下检查应在干净的 Windows 10 x64 和 Windows 11 x64 环境中使用 Release 构建执行。

## 构建与启动

- [ ] MSVC `/W4` 构建无警告，CTest 全部通过。
- [ ] 仅复制 `SuperDrag.exe` 到另一目录即可运行，无缺失运行时 DLL。
- [ ] EXE、标题栏和托盘图标为蓝色，16/20/24/48/256px 尺寸均无右侧或底部裁切。
- [ ] 首次运行显示设置窗口并创建托盘图标；退出后再次运行只显示托盘图标。
- [ ] `Enabled=1` 时连续启动退出 10 次，每次均自动显示托盘“暂停”，无需手动重试。
- [ ] 模拟首次钩子安装失败时按 250ms/1s/3s 自动重试；最终失败后显示“重试启用”和完整错误码。
- [ ] 连续启动第二个实例时，不新增进程或托盘图标，并打开已有实例的设置窗口。
- [ ] 结束并重新启动 Explorer 后，托盘图标自动恢复且功能仍可用。

## 拖动行为

- [ ] 不按快捷键时，窗口中的点击、选择和拖动行为完全不变。
- [ ] 默认 `Win+Alt` 可从记事本、资源管理器和浏览器客户区拖动窗口。
- [ ] 记事本、资源管理器和浏览器分别连续拖动至少 60 秒，窗口始终跟随，释放后立即停止。
- [ ] 繁忙窗口（多标签浏览器、大型 IDE、正在编译的项目）拖动平滑跟随，无抖动和橡皮筋式跳动。
- [ ] 高回报率鼠标（500Hz/1000Hz）拖动平滑，无异常 CPU 占用。
- [ ] 正常目标进入 Windows 原生移动循环，支持 Win11 Snap、最大化拖出恢复和 Esc 取消。
- [ ] 自定义窗口拒绝原生标题栏消息时自动进入手动回退，最终实际位置与释放坐标一致。
- [ ] Trace 只记录原生请求/开始/结束/返回和手动回退汇总，不出现每个鼠标移动事件的日志。
- [ ] 在 Windows 中交换主/次鼠标键后，使用逻辑左键持续拖动 2 秒以上仍不中断。
- [ ] 从后台窗口开始拖动时，该窗口被激活并置前。
- [ ] 拖动开始后先松开 Win/Alt，窗口仍跟随鼠标直至左键释放。
- [ ] 同时按住额外的 Ctrl 或 Shift 时，默认快捷键不会触发。
- [ ] 拖动期间，左键按下和释放不会触发目标窗口内的控件；光标移动连续，且不会启动控件拖选。
- [ ] 拖动中因任何原因中断后（如目标窗口无响应），后续普通点击不被吞掉。
- [ ] 调试时暂停主线程超过 `LowLevelHooksTimeout` 后恢复，松开按键可结束状态，下一次拖动仍可启动。
- [ ] 最大化窗口按系统标题栏语义恢复，鼠标锚点和 Snap 表现与原生顶栏拖动一致。
- [ ] 贴靠窗口、负坐标显示器和不同 DPI 缩放比例下拖动连续且无明显跳跃。
- [ ] 桌面、任务栏、托盘菜单、工具提示和 SuperDrag 自身窗口不会被拖动。
- [ ] 其他注入式输入工具（如宏软件）的合成鼠标流不会触发或干扰拖动。

## 设置与权限

- [ ] 选择 0 个或 4 个修饰键时拒绝保存，原设置保持不变。
- [ ] 选择 1 至 3 个修饰键后保存，变更立即生效且重启后保留。
- [ ] 在与主屏 DPI 不同的显示器上首次打开设置页，窗口和控件尺寸正确且无裁切。
- [ ] 设置页的 Tab/Alt 助记符可用；Enter/Escape 符合原生默认按钮和取消语义。
- [ ] 托盘“暂停/启用”状态立即生效并在重启后保留。
- [ ] 开机启动开启、关闭和 EXE 移动后的路径刷新均正确。
- [ ] 拖动管理员权限窗口时不弹 UAC、不移动窗口，并只显示一次权限说明。
- [ ] 普通窗口移动失败时不会把不完整的拖动输入传给目标控件。

## 资源占用

- [ ] 空闲 60 秒时无持续 CPU 活动，任务管理器 CPU 显示接近 0%。
- [ ] 干净启动后的私有工作集低于 10 MB；记录实际数值。
- [ ] 连续完成 500 次拖动后，句柄数和私有工作集无持续增长。
- [ ] 记录 Release EXE 的实际文件大小。
