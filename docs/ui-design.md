# NekoDrag UI 设计规范

> 版本：v1.0
> 目标：为 NekoDrag 设置窗口提供现代、清晰、可访问的界面，同时保持原生 Win32 单文件便携性。

## 1. 设计目标

- **品牌化**：摆脱默认 `IDI_APPLICATION`，使用专属应用图标与托盘图标。
- **现代感**：采用 Windows 11 Fluent 风格的浅色/深色配色、圆角按钮、清晰层级。
- **清晰布局**：重新组织设置窗口，让“启用开关、快捷键、开机启动、帮助/状态、操作按钮”的层级一目了然。
- **可访问性**：支持键盘 Tab 导航、Alt+字母 快捷键、高对比度主题。
- **响应式**：窗口支持缩放，底部按钮锚定右下角；在不同 DPI 下保持清晰。

## 2. 设计原则

1. **克制**：NekoDrag 是后台工具，UI 只在设置窗口短暂出现，不应过度设计。
2. **原生优先**：不引入第三方 UI 框架，使用 Win32 自定义绘制与 DWM 原生深色标题栏。
3. **跟随系统**：深浅模式、高对比度都跟随 Windows 设置，而不是自定义主题引擎。
4. **清晰反馈**：状态文本使用颜色区分成功/错误；保存/取消行为明确。

## 3. 窗口布局

### 3.1 尺寸与网格

- **客户区基准尺寸**：480 × 500 逻辑像素。
- **最小客户区**：480 × 500（不可再小）。
- **网格基线**：8px。
- **外边距**：左右下 24px，顶部 20px。
- **区块间距**：24px。
- **相关控件间距**：16px。
- **控件行高**：28px。
- **按钮尺寸**：76 × 28px；按钮间距 12px。

### 3.2 布局草图

### 3.3 控件顺序（Tab 顺序）

按视觉阅读顺序创建控件，从而得到自然的 Tab 顺序：

1. 启用窗口拖动(E)
2. Win(W)
3. Ctrl(C)
4. Alt(A)
5. Shi-ft
6. 自动（推荐）
7. 仅 SC_MOVE
8. 仅兼容模式
9. 登录 Windows 时自动启动(U)
10. 保存(S)
11. 取消(X)

分组框本身不参与 Tab 导航。

## 4. 配色

### 4.1 Light 模式

| Token | 色值 | 用途 |
|---|---|---|
| `background` | `#FFFFFF` | 窗口客户区背景 |
| `surface` | `#F3F3F3` | 卡片/分组框背景、按钮 idle 背景 |
| `textPrimary` | `#1A1A1A` | 主要文本 |
| `textSecondary` | `#5C5C5C` | 帮助文本、次要说明 |
| `accent` | `#0078D4` | 默认按钮背景、复选框选中、聚焦边框 |
| `accentHover` | `#106EBE` | 默认按钮悬停 |
| `border` | `#E0E0E0` | 按钮边框、分组框边框 |
| `success` | `#107C10` | 成功状态文本 |
| `error` | `#D13438` | 错误状态文本 |

### 4.2 Dark 模式

| Token | 色值 | 用途 |
|---|---|---|
| `background` | `#202020` | 窗口客户区背景 |
| `surface` | `#2D2D2D` | 卡片/分组框背景、按钮 idle 背景 |
| `textPrimary` | `#FFFFFF` | 主要文本 |
| `textSecondary` | `#A0A0A0` | 帮助文本、次要说明 |
| `accent` | `#4CC2FF` | 默认按钮背景、复选框选中、聚焦边框 |
| `accentHover` | `#60CDFF` | 默认按钮悬停 |
| `border` | `#3C3C3C` | 按钮边框、分组框边框 |
| `success` | `#54B054` | 成功状态文本 |
| `error` | `#FF7B7B` | 错误状态文本 |

### 4.3 状态颜色

- 普通状态文本：使用 `textSecondary`。
- 错误：使用 `error`。
- 成功：使用 `success`（例如保存成功后的短暂提示，可选）。

### 4.4 高对比度模式

当检测到 `SPI_GETHIGHCONTRAST` 时，禁用所有自定义调色板，完全使用 `GetSysColor` / `GetSysColorBrush` 与系统绘制函数（`DrawFrameControl`、`DrawFocusRect`），确保用户自定义的高对比度主题生效。

## 5. 字体

- **字体族**：`Segoe UI`。
- **正文/复选框/按钮/分组框**：9pt 常规。
- **帮助文本**：9pt 常规，颜色 `textSecondary`。
- **状态文本**：8.5pt 常规，颜色根据状态变化。
- **可选品牌标题**：14pt 半粗（如果窗口顶部添加“NekoDrag”大标题）。

所有字号都通过 `MulDiv(size, dpi, 72)` 按当前 DPI 缩放，使用负高 `CreateFontW`。

## 6. 图标

### 6.1 应用图标 `app.ico`

- 资源 ID：`IDI_APPICON`（101）。
- 用途：窗口标题栏、Alt-Tab、EXE 文件图标。
- 尺寸：16×16、20×20、24×24、32×32、48×48、256×256。
- 风格：透明背景的日系二次元萌系双色布偶猫头像，使用干净线稿、赛璐璐明暗和平滑轮廓，不使用像素风。保留宽阔蓬松脸型、对称的白色倒 V 脸纹、海豹棕耳朵与脸侧、亮蓝眼睛和粉色鼻子；画面下方有且仅有两只向镜头前伸、肉垫可见的猫爪，形成抓取屏幕前物体的透视动作，同时不得遮挡脸部特征或使用暹罗猫式整脸深色面罩。

### 6.2 托盘图标 `tray.ico`

- 资源 ID：`IDI_TRAYICON`（102）。
- 用途：通知区域。
- 尺寸：16×16、20×20、24×24。
- 风格：与应用图标使用同一透明 PNG 母版；通过高质量抗锯齿缩放保留猫耳、白色倒 V、蓝眼和双爪前伸的轮廓，不添加文字、背景方块或额外拖动符号。

### 6.3 源文件

`assets/nekodrag.png` 是透明高分辨率母版。`scripts/generate_icons.py` 使用
Pillow 的 Lanczos 重采样生成 `app.ico` 与 `tray.ico` 的全部尺寸。Pillow 仅是
开发期资源生成依赖，必须安装在项目虚拟环境中，不进入最终 EXE。

## 7. 控件样式

### 7.1 复选框

- 未选中：白色/深色表面小方框，1px `border` 色边框，圆角 2px。
- 选中：背景填充 `accent`，内部绘制白色/深色对勾。
- 悬停：边框颜色加深为 `accent`。
- 文本位于方框右侧，垂直居中对齐。
- 高对比度模式：使用系统 `DrawFrameControl(DFC_BUTTON, DFCS_CHECKED)`。

### 7.2 按钮

- **默认按钮（保存）**：
  - 背景：`accent`
  - 文本：深色/浅色对比色（浅色模式下白色，深色模式下 `#1A1A1A`）
  - 悬停：`accentHover`
  - 按下：略深
  - 圆角：3px
- **普通按钮（取消）**：
  - 背景：`surface`
  - 文本：`textPrimary`
  - 边框：1px `border`
  - 悬停：背景略亮/略暗
  - 圆角：3px
- 高对比度模式：使用系统按钮绘制。

### 7.3 分组框

- 背景：`surface`
- 边框：1px `border`
- 圆角：4px
- 标签位于左上角内边距处，背景与分组框同色以形成“缺口”效果。

### 7.4 状态文本

- 左对齐，位于帮助文本下方。
- 错误时显示 `error` 色，普通提示使用 `textSecondary`。

## 8. 交互行为

- **打开设置**：
  - 托盘图标左键单击打开设置窗口。
  - 右键菜单选择“设置…”打开。
  - 单实例运行时再次运行 EXE 会唤醒已运行实例并打开设置。
- **保存**：
  - 校验修饰键数量（1–3 个）。
  - 非法时状态栏显示错误，不关闭窗口。
  - 合法时写入注册表并隐藏窗口。
- **取消**：隐藏窗口，不保存任何更改。
- **关闭按钮（X）**：与取消一致，隐藏窗口。
- **主题切换**：
  - 窗口打开时检测当前主题。
  - Windows 主题切换时，已打开窗口应自动刷新（监听 `WM_SETTINGCHANGE` / `WM_THEMECHANGED`）。

## 9. 可访问性

- 所有交互控件都有 `&` 助记符。
- Tab 顺序与视觉顺序一致。
- 高对比度模式下完全回退系统主题。
- 控件文本避免使用纯颜色作为唯一信息通道（例如错误状态同时改变文字内容）。

## 10. 响应式/DPI

- 所有布局尺寸均为 96-DPI 逻辑像素，运行时通过 `MulDiv(value, dpi, 96)` 缩放。
- `WM_DPICHANGED` 时使用系统建议的窗口矩形并重布局。
- `WM_SIZE` 时根据新客户区宽度重新锚定右下角按钮。
- 使用 `DeferWindowPos` 批量移动控件，避免缩放闪烁。
